# Requirements

Before installing the **Magento 2 Multi Shopify Store Connector**, please ensure your server and Magento instance meet the following requirements.

---

## Required Store Setup

* **Magento Setup:** A working installation of Magento 2 / Adobe Commerce (supports versions 2.0.x through 2.4.x).
* **PHP Compatibility:** A PHP version that is compatible with your active Magento 2 setup.
* **Production Environments:** Must use valid public HTTPS domain URLs with trusted SSL certificates.

---

## Shopify Store Access

To integrate this module, you must have an active Shopify store account with admin API access permissions to generate API keys.

---

::: tip Important
Always back up your store (database and files) before installing any new extension. We recommend deploying and testing in a staging environment first.
:::
