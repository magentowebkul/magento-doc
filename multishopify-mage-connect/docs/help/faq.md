# FAQ

**Q: Can I connect multiple Shopify stores to one Magento 2 installation?**

A: Yes, you can add and manage multiple Shopify accounts right from the single connector settings panel.

**Q: Are configurable products supported?**

A: Yes, both Simple and Configurable products can be seamlessly imported and exported between the platforms.

**Q: Is there an automatic way to sync orders?**

A: Yes, the module includes a built-in cron job that runs every hour by default to automatically synchronize orders in the background.

**Q: Does the module support real-time synchronization?**

A: Yes, you can utilize the Shopify Webhooks feature by adding your Magento endpoint to Shopify's webhook settings. This allows real-time updates for products when changes happen on Shopify.

**Q: Can I sync existing Magento customers to Shopify?**

A: Absolutely! The extension provides a feature to export your existing Magento customers directly to Shopify. Furthermore, you can trigger a "reset password" email for them directly from your Magento admin panel to help them activate their Shopify accounts.

**Q: How does the category mapping work?**

A: Category mapping allows you to link specific Magento categories with Shopify categories. During the product import process, products will automatically be assigned to these mapped categories. Note that you can only map child (leaf) subcategories, and parent category mapping is not allowed.

**Q: Are images synced with products?**

A: Yes, the module provides a dedicated image profiler that you can run to fetch and assign all product images from Shopify during product images import.
