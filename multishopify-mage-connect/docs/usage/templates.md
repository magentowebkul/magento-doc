# Templates

## Additional Product Information Templates
This module allows the admin to export the product’s additional information along with the product using templates.

Navigate to **Webkul Shopify Connector -> Templates**.

![Templates Menu](/images/webkul-magento2-shopify-connector-sidepanel-6.webp)

Here, you can view, edit, delete, or add an unlimited number of templates.

![Listing Templates](/images/webkul-magento2-shopify-connector-listing-templates.webp)

### Create Template
Click **Create Template** and configure:

![Create Template](/images/webkul-magento2-shopify-connector-create-template.webp)

- **Title**: Enter the template name.
- **Template Content**: Define the template variables.
- **Status**: Enable or disable the template.
- Map the Magento store product attributes to the configured template variables defined in the Template Content field.

::: tip Note
Each variable should be unique within the same template. When the product is exported, the additional details will also be exported to the Shopify store.
:::
