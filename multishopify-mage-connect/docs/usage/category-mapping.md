# Category Mapping

## Map Magento Category with Shopify Category
The admin can map the Magento 2 store categories with the Shopify store categories by clicking on the **Category Mapping** tab in Shopify Connect configuration.

![Category Mapping](/images/webkul-magento2-shopify-connector-map-category-1.webp)

For mapping, select the Magento Store Category which the admin wants to map with the Shopify store Category.

::: tip Note
- Only one category will map at a time.
- You cannot map the parent categories. You need to select the sub-category.
- Only manual collections of the Shopify store will be visible at the Magento end for mapping.
:::

![Category Assigned](/images/webkul-magento2-shopify-connector-leaf-category-mapping-1.webp)

For successful mapping, hit the **Save Mapping** button.

![Category Assigned](/images/webkul-magento2-shopify-connector-category-map-successfull.webp)
