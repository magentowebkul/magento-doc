# Export Products

## Export Products To Shopify
The admin can export products from the Magento store to their Shopify store by clicking on the **Export Products To Shopify** tab.

1. Select the products you want to export.
2. Select **Export to Shopify** from the Action dropdown.
3. Click the **Submit** button.

![Export Products to Shopify](/images/webkul-magento2-shopify-connector-export-3.webp)

4. This navigates you to the "Run Profile" page where the execution occurs.

![Export Products Profiler](/images/export-product-profile-1.png)

::: tip Note
- If category mapping is not done for the Shopify product category, the products will not be exported.
- Both Simple and Configurable products can be exported.
- Product information such as the base image, name, price, and quantity are exported.
- If exporting a product with no description, its name will be used as the description (Shopify requires a description).
:::

![Shopify Exported Products](/images/shopify-product-that-exported-e1634890281206.png)

After successful execution, you can see the exported products in the Shopify Store.

![Shopify Exported Products](/images/exported-products-e1634890437911.png)
