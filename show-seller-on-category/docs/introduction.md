# Introduction

**Magento 2 Marketplace Show Seller on Category** extension enables store owners to display and filter marketplace sellers directly on category pages.

By allowing customers to search and filter sellers by ratings, location/country, and other metrics directly on the category page, this module increases seller visibility and enhances the customer's navigation and shopping experience. The extension features two main category display modes: showing sellers only, or showing a hybrid list of both products and sellers.

::: tip
To use this module, you must install the [Magento 2 Multi Vendor Marketplace](https://store.webkul.com/magento2-multi-vendor-marketplace.html) first.
:::

## Features

- Display marketplace sellers directly on category pages.
- Add **Sellers Only** and **Hybrid (Products & Sellers)** display modes to categories.
- Provide a layered navigation sidebar to search and filter sellers by rating and country.
- Allow administrators to toggle rating, product count, and order count displays on seller cards.
- Integrated GraphQL API support to fetch category sellers and filter options for headless commerce.
