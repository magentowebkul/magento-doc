# System Requirements

Before installing the **Webkul Magento 2 Multi Vendor Dropship Extension**, ensure your environment meets the system specifications outlined below.

---

## Prerequisites & Dependencies

::: important Marketplace Dependency
This extension is a **Marketplace Add-on**. You must have **[Webkul Magento 2 Multi Vendor Marketplace](https://store.webkul.com/magento2-multi-vendor-marketplace.html)** installed and configured in your Magento environment prior to installing this extension.
:::

---

## Supported Magento & PHP Versions

| Component | Minimum Supported | Recommended / Tested |
| :--- | :--- | :--- |
| **Magento Version** | Magento Open Source / Adobe Commerce 2.0.x – 2.4.x | **Magento 2.4.4, 2.4.5, 2.4.6, 2.4.7, 2.4.8, 2.4.9+** |
| **PHP Version** | PHP 7.4 (for legacy M2 versions) | **PHP 8.1, 8.2, 8.3, 8.4, 8.5+** |
| **Database** | MySQL 8.0 or MariaDB 10.4+ | MySQL 8.0+ |
| **Search Engine** | OpenSearch 1.x / 2.x or Elasticsearch 7.x | OpenSearch 2.x |
| **Web Server** | Apache 2.4 or Nginx 1.18+ | Nginx with PHP-FPM |
| **External APIs** | Google Maps Platform API Key | Maps JavaScript API, Geocoding API, Places API |

---

## Supported Shipping Methods

The module works seamlessly with Magento's standard shipping infrastructure:

1. **Table Rate Shipping**
2. **Free Shipping**
3. **DHL**
4. **UPS**
5. **USPS**
6. **FedEx**
