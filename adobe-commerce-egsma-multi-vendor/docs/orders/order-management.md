# Order & Inventory Management

Vendors manage orders and stock from the EGSMA panel. The system keeps order and stock data synchronized with Adobe Commerce automatically.

---

## Order Operations

| Operation | What it does |
|---|---|
| **Order Created** | New orders from the Adobe Commerce store appear in the EGSMA store automatically. |
| **Order Updated** | Order status changes are synced. |
| **Order Fulfillment** | Fulfillment status is managed between Adobe Commerce and the EGSMA store. |
| **Returns & Refunds** | Returns and refunds are handled in Adobe Commerce. |
| **Shipment Created** | Shipping information syncs from Adobe Commerce to EGSMA, and vice versa. |
| **Shipment Updated** | Shipment information is updated in both directions. |

### Customer Data

- Customer accounts are kept synchronized between both stores.
- Customer data syncs **only** as part of order synchronization.

---

## Inventory / Stock Management

Stock levels stay synchronized in real time across both platforms.

- **Stock Updated:** When inventory changes in one system, it updates automatically in the other.
- **Stock Sync:** Stock quantities stay consistent across platforms.
