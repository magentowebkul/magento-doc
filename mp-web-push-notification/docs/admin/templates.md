# Admin Notification Templates

Store administrators can create, edit, filter, and delete rich push notification templates in the admin backend.

---

## Accessing Notification Templates

1. Navigate to **Marketplace Management > Push Notification Manager**.
2. Click **Notification Templates**.

![Admin Menu Navigation](/images/image-16.png)

The templates grid displays all saved push notification templates.

![Notification Templates Grid](/images/image-17.png)

---

## Creating a New Template

1. On the **Notification Templates** grid page, click **Create New** at the top right.
2. Complete the template fields:

| Field | Description |
| :--- | :--- |
| **Template Title** | Headline text displayed in the push notification alert. |
| **Template Message** | Main body message text of the notification. |
| **Redirect URL** | Destination web page URL opened when the user clicks the push alert. |
| **Template Tags** | Categorization tags or internal labels for organizing templates. |
| **Template Logo** | Image/logo icon displayed alongside the notification message. |

![Create New Template Form](/images/image-18.png)

3. Click **Save Template**.

---

## Deleting Notification Templates

1. Go to **Marketplace Management > Push Notification Manager > Notification Templates**.
2. Select the templates to remove using individual checkboxes.
3. From the **Actions** dropdown menu, select **Delete**.
4. Confirm the prompt by clicking **OK**.

![Delete Template Action](/images/image-19.png)
