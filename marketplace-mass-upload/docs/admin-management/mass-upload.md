# Admin Mass Upload for Individual Seller

Store administrators can perform mass product uploads on behalf of specific marketplace sellers directly from the Magento Admin Panel.

---

## Uploading Products for a Specific Seller

1. In the admin backend menu, navigate to **Marketplace Management > Mass Upload Manager**.

![Admin Mass Upload Manager Navigation](/images/image-44.png)

2. Choose the file type (CSV, XLS, XML), select the data file, and attach the Image ZIP folder.
3. (If applicable) Check **Is Downloadable** for downloadable products.
4. Click **Upload Profile**.

![Admin Upload File & Image ZIP Form](/images/image-45.png)

5. A green status alert will confirm that the file was uploaded and unpacked successfully.

![Admin Upload & Unpack Success Alert](/images/image-46.png)

6. Go to **Run Mass Upload Profile**, select the target **Seller** from the drop-down menu, and select the uploaded profile.

![Select Seller and Profile for Execution](/images/image-47.png)

7. Click **Run Profile**. The execution window displays live batch progress as products are assigned to the target seller.

![Admin Profiler Execution Progress Window](/images/image-48.png)

8. Once finished, verify the newly uploaded seller products under **Marketplace Management > Manage Product**.

![Manage Seller Products Grid in Admin Panel](/images/image-49.png)
