# Admin Dataflow, Export & Profile Listing

Administrators have central control over column mapping, catalog exports per seller, and profile cleanup.

---

## Admin Mass Upload Dataflow Profile

Administrators can set up global field mapping profiles:

1. Click **Mass upload Dataflow Profile** in the admin mass upload manager.

![Admin Mass Upload Dataflow Profile Button](/images/image-54.png)

2. Enter the **Profile Name** and select the target **Attribute Set**.

![Admin Add Profile Setup Screen](/images/image-55.png)

3. Map the **In File Name** (custom CSV header) to the corresponding Magento **Database Attribute** and click **Save**.

![Admin Field Mapping Table](/images/image-56.png)

---

## Admin Mass Product Export

Administrators can export products for any seller:

1. Navigate to **Marketplace Management > Manage Mass Product Export**.
2. Select the target **Seller**.
3. Select the **Product Type** to export.

![Admin Manage Mass Product Export Filters](/images/image-57.png)

4. Click **Export** to download the CSV file.

---

## Admin Mass Upload Profile Listing

To inspect or remove unexecuted profiles across all sellers:

1. Navigate to **Marketplace Management > Mass Upload Profile Listing**.
2. Filter profiles by seller or status, and delete obsolete or failed profile records.

![Admin Mass Upload Profile Listing Grid](/images/image-58.png)
