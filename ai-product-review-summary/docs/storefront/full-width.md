# Full-Width Layout

Page Builder's **Product -- Full Width** layout has no Reviews tab. Instead it renders the
reviews in a section further down the page.

For products using that layout, the module places the same **Customers Say** block at the
top of that reviews section.

## Setting the layout

**Catalog → Products → *edit product* → Design → Layout → Product -- Full Width**

## Differences from the standard layout

| | Standard layouts | Product -- Full Width |
| --- | --- | --- |
| Position | Top of the **Reviews** tab | Top of the reviews section |
| `**bold**` Markdown | Rendered as bold | Shown as literal asterisks |
| Shown when | Module enabled, summary exists, approved reviews > 0 | Same |
