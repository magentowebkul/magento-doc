# Bulk Generation (Seller)

Sellers can generate content for many products at once from their product list.

---

## Generate Content for Many Products

1. In your seller account, open **Products > My Products List**.
2. Select the products.
3. Open **Actions > Import AI Content**.
4. Choose an option:
   * **Product Content** — writes the allowed product attributes.
   * **SEO Content** — writes the meta fields. Shown only when the admin turns on SEO content.
5. Click **OK** in the confirmation **"Are you sure want to import AI Content For selected items?"**

![Import AI Content mass action on the seller product list](/images/seller/mass-content-generation-option.webp)

---

## The Run Profile Page

The **Run Profile** page opens and processes the products one by one.

![Seller Run Profile page](/images/seller/bulk-content-generation-profiler.webp)

::: warning
Do not close or refresh the window while it runs.
:::

Each product shows **AI Content imported successfully.** or **AI Content not imported.**

**Finished Execution.** means the run is done. Click **Go Back** to return to your product list.

::: tip
If you use the admin LLM configuration, each product counts toward your request limit. Select fewer products if you see **"Rate limit exceeded. Please try again after some time."**
:::
