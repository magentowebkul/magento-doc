# Introduction

**Magento 2 Shippo Shipping** connects your Magento 2 / Adobe Commerce store cart directly to global parcel carriers, shows real-time checkout freight rates, validates customer shipping addresses, and generates compliant carrier shipping labels in admin.

By integrating Shippo's multi-carrier logistics network into Magento, merchants eliminate manual rate tables, automate box dimension calculations, and streamline order dispatch without needing individual direct carrier accounts.

---

## Key Features

- **Live Freight & Parcel Rates:** Fetch real-time shipping quotes from global carriers (USPS, UPS, FedEx, DHL Express, and regional couriers) during cart and checkout.
- **Smart Address Validation:** Real-time verification checks customer street lines, unit numbers, and postal codes to stop failed deliveries and carrier address correction penalties.
- **Automated Box Dimension Calculations:** Computes parcel box dimensions and billable weights based on catalog product lengths, widths, and heights.
- **Printable Carrier PDF Labels:** Generate official, verified carrier shipping slips directly from the order shipment view inside the Magento Admin backend.
- **End-to-End Package Tracking:** Automatically attaches official carrier tracking numbers to shipments, providing direct clickable tracking URLs inside customer account dashboards.
- **Fallback Rate Guidance:** Set custom error guidance messages to inform shoppers whenever carrier networks are unreachable.
- **Hyvä Theme Support:** Native integration package (`Webkul_ShippoShippingHyva`) providing Alpine.js and Magewire-powered real-time address validation for Hyvä storefronts.
