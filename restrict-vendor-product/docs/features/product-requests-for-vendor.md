# Product Requests For Vendor

The admin can approve or reject the product requests submitted by the vendor from the admin backend.

When a vendor requests to add a product, it goes into a pending state. The admin can review the product details and choose to either approve or reject the request.

![Product Requests For Vendor](/images/webkul-magento2-restrict-vendor-product-approve-reject-vendor-product-request.webp)

Once approved, the product becomes active and is available for vendor to view and edit from vendor panel. If rejected, the vendor will be notified.
