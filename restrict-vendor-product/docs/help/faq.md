# Frequently Asked Questions

**Q: Do I need the Multi-Vendor Marketplace extension for this to work?**  
A: Yes. The **Magento 2 Marketplace Restrict Vendor Product** is an add-on module to the [Magento 2 Multi Vendor Marketplace](https://store.webkul.com/magento2-multi-vendor-marketplace.html). It will not work standalone.

**Q: Can vendors edit all product attributes?**  
A: No, vendors can only edit the attributes that the admin explicitly allows in the configuration settings (**Stores -> Configuration -> Webkul -> Marketplace Restrict Vendor Product -> Allow Default Attributes To Edit**).

**Q: Can vendors request multiple products at once?**  
A: Yes, sellers can select and request multiple admin products in one go from their vendor panel.

**Q: Can the admin approve multiple product requests simultaneously?**  
A: Yes, the admin can review and manage all product access requests submitted by vendors, and they can approve or reject selected requests in bulk.

**Q: Will vendors be notified about the status of their requests?**  
A: Yes, email notifications can be configured to inform vendors about their request status (approved or rejected) using custom templates.
