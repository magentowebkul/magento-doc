# Frequently Asked Questions

### Is Webkul Multi-Vendor Marketplace required to run this extension?
Yes. Magento 2 Marketplace Campaign is an add-on module and requires Webkul Multi-Vendor Marketplace version `5.0.0` or higher.

---

### Can sellers create their own campaigns?
No. Store admins create campaigns, set promotional rules, and invite sellers. Sellers decide whether to join and choose which products to participate with.

---

### Which discount types are supported?
The extension supports four promotional rule types:
- Percent of product price discount
- Fixed amount discount
- Fixed amount discount for whole cart
- Buy X get Y Free

---

### Can multiple campaign discounts be applied together?
Yes, unless the admin enables **Discard Subsequence Rules** on a specific campaign, which prevents discount stacking.

---

### Does this extension support multi-store and multi-lingual setups?
Yes. You can target specific websites, configure localized email templates, and translate CSV files (`i18n/de_DE.csv`) with full LTR and RTL support.
