# Seller Product Workflow

Marketplace sellers can create products in their native language and let the extension handle translations across all store views automatically.

---

## Creating a Translated Product in Seller Panel

1. Log in to the Marketplace **Seller Account Panel**.
2. Navigate to **My Account > New Products** (or edit an existing product in **My Product List**).
3. Select the **Attribute Set** and **Product Type**, then click **Continue**.
4. To view or manage translations for specific store views, use the **Store View** dropdown menu located in the top-right header area.

![Seller Select Store View Step 1](/images/image-10.png)
![Seller Select Store View Step 2](/images/image-11.png)

5. Upon selecting the store view, all text input fields—such as Product Name, Description, and Short Description—translate automatically to match the locale of the selected store view.

![Seller Translated Form Part 1](/images/image-12.png)
![Seller Translated Form Part 2](/images/image-13.png)

6. Click **Save** to submit the product.

::: tip Seller Convenience
Sellers do not need to speak foreign languages or manually fill in translated text fields. The extension handles background translation via Google Cloud API instantly.
:::
