# Admin Catalog Workflow

Store administrators can manage and view translated categories and products directly within the Magento 2 Admin Panel.

---

## Category Translation Workflow

1. In the Magento Admin Panel, navigate to **Catalog > Categories**.
2. Select an existing category or click **Add Subcategory**.
3. Use the **Store View** dropdown menu in the upper-left corner to select your target language store view (e.g., *Arabic Store View* or *German Store View*).

![Select Category Store View](/images/image-6.png)

4. Once the store view is selected, category titles and descriptions automatically translate into the locale language specified for that store view.

![Translated Category View](/images/image-7.png)

---

## Product Translation Workflow

1. Navigate to **Catalog > Products**.
2. Create a new product or edit an existing product.
3. Switch the **Store View** selector in the top-left menu bar.

![Select Product Store View](/images/image-8.png)

4. All text attributes—including product title, description, short description, meta attributes, and custom input fields—translate automatically into the selected store view language.

![Translated Admin Product Attributes](/images/image-9.png)

5. Click **Save** to persist translations for the store view.
