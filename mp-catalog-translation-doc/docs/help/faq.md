# FAQ & Support

Frequently Asked Questions and technical support resources for **Marketplace Catalog Translation for Magento 2**.

---

## Frequently Asked Questions

### Q1: Is this extension compatible with Hyvä Themes?
Yes! The extension translates backend data attributes and API responses, making it compatible with both default Luma themes and Hyvä storefront themes.

### Q2: Does the extension translate custom seller product attributes?
Yes, any seller-created text fields (product name, description, short description, custom text attributes) are sent to Google Translate when switching store views.

### Q3: Does the extension support offline / manual translation overrides?
Yes. You can edit translated fields in the admin panel for specific store views and save manual overrides.

### Q4: Which Magento editions are supported?
The module supports Magento Open Source (Community) and Adobe Commerce (Enterprise/Cloud) versions 2.0.x through 2.4.x.
