# Troubleshooting Guide

This guide assists store administrators, technical merchants, and developers in diagnosing and resolving common operational issues encountered with the **Webkul Magento 2 Make An Offer** extension.

---

## 1. Make An Offer Button Does Not Appear on Product Page

### Symptom
The **Make An Offer** button or popup trigger does not display on the storefront product page.

### Diagnostics & Solutions
1. **Verify Global Module Status**:
   - Navigate to **Stores > Configuration > Webkul > Make An Offer**.
   - Ensure **Enable** is set to **Yes**.
2. **Verify Product & Category Offer Attributes**:
   - Open **Catalog > Products** and edit the target product.
   - Verify that **Allow Offer On Product** is set to **Yes**, OR that the product is assigned to a category where **Allow Offer On Category** is **Yes**.
3. **Verify Product Type Support**:
   - Confirm that the product is a **Simple**, **Configurable**, **Virtual**, or **Downloadable** product. Bundle and Grouped products are not supported.
4. **Flush Magento Caches**:
   ```bash
   php bin/magento cache:flush
   ```
   <ExplainCode explanation="Flushes Magento's configuration and block HTML cache to ensure newly saved attributes take effect." />

## 2. Product Tab Form Does Not Render on Storefront

### Symptom
When **Offer Display Type** is set to `Product tab` or `Both`, the offer tab does not appear in the product information section.

### Diagnostics & Solutions
1. **Inspect Product Design Layout Setting**:
   - Edit the product under **Catalog > Products**.
   - Expand the **Design** section.
   - Verify that **Layout Update** is set to **No layout updates** so standard product detail page tabs are not overridden by a custom canvas layout.
2. **Check Display Type Setting**:
   - In **Stores > Configuration > Webkul > Make An Offer > Offer PopUp Form Settings**, ensure **Offer Display Type** is configured as `Product tab` or `Both`.
3. **Flush Layout and Full Page Cache**:
   ```bash
   php bin/magento cache:flush
   ```
   <ExplainCode explanation="Purges page layout and block caches to render the tab block." />

## 3. Guest Users Unable to Submit Offers

### Symptom
Unauthenticated visitors visiting the product page cannot view the offer form or are prompted to log in.

### Diagnostics & Solutions
1. **Verify Guest User Permission**:
   - Go to **Stores > Configuration > Webkul > Make An Offer > Offer PopUp Form Settings**.
   - Ensure **Allowed For Guest User** is set to **Yes**.
2. **Flush Configuration Cache**:
   ```bash
   php bin/magento cache:flush
   ```
   <ExplainCode explanation="Refreshes configuration cache to allow guest submissions immediately." />

## 4. Customer Receives Duplicate Offer Alert

### Symptom
When submitting an offer, the customer is prevented from submitting and receives a notification that an active offer already exists.

### Diagnostics & Solutions
1. **Expected Safeguard Behavior**:
   - To prevent database flooding and spam, the module intentionally restricts a customer or guest session to **one active pending offer per product SKU**.
2. **Resolving the Offer**:
   - The store administrator can evaluate, accept, or decline the existing pending quotation under **Make An Offer > Manage Offer**.
   - Once the existing offer is accepted or declined, the customer can submit a subsequent negotiation request.

## 5. Discount Not Applied in Shopping Cart After Clicking "Buy Here"

### Symptom
When clicking the "Buy Here" button or the link in the promotional email, the product is added to the cart, but no discount is deducted.

### Diagnostics & Solutions
1. **Check Promotion Expiration Date**:
   - In the Magento Admin Panel, open **Make An Offer > Manage Offer** and view the offer details.
   - Open the **Recent Promotions** tab and check if the promotion has lapsed past its configured **Number of Days**.
   - If expired, the promotional coupon is automatically moved to the **Old Promotions** tab and deactivated.
2. **Inspect Cart Price Rules**:
   - Ensure the coupon generated by the module is active under **Marketing > Promotions > Cart Price Rules**.
3. **Reindex Promotion Indexes**:
   ```bash
   php bin/magento indexer:reindex
   php bin/magento cache:flush
   ```
   <ExplainCode explanation="Rebuilds price and sales rule indexes to guarantee coupon application." />

## 6. Offer Discussion Messaging Locked / Disabled

### Symptom
The customer or admin cannot send messages in the discussion panel; the input area is disabled.

### Diagnostics & Solutions
1. **Check Discussion Block Status**:
   - On the admin offer view (**Make An Offer > Manage Offer > View**), check if the discussion was previously blocked.
2. **Reopen Discussion**:
   - If blocked, click **Reopen Discussion** in the top action bar to restore messaging privileges.

## 7. Google reCAPTCHA Verification Error on Submission

### Symptom
Shoppers submitting the offer encounter a reCAPTCHA verification failure error.

### Diagnostics & Solutions
1. **Verify API Credentials**:
   - Navigate to **Stores > Configuration > Security > Google reCAPTCHA Storefront**.
   - Ensure valid Google reCAPTCHA API Keys (Website Key and Secret Key) are configured.
2. **Domain Matching**:
   - Confirm that your store domain is listed under the authorized domains in your Google reCAPTCHA admin console.
