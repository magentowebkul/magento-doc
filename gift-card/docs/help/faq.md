# FAQ & Support

Frequently asked questions and support resources for the **Magento 2 Gift Card** extension.

---

## Frequently Asked Questions

### Can a customer use a gift card multiple times if balance remains?
**Yes.** When a customer applies a gift card code to an order that is less than the card's total value, the remaining unspent credit is preserved. The customer can use the same voucher code on subsequent purchases until the balance reaches zero or the card expires.

### Can customers combine multiple gift cards on a single order?
**No.** Customers can apply **one active gift card code** per order. If a customer holds multiple gift cards, they can redeem them across separate transactions.

### Can gift cards be combined with discount coupon codes?
**Yes.** Because gift cards function as a tender discount rather than a promotional sales rule coupon, shoppers can apply standard promotional coupons (e.g., percentage discounts, free shipping) and apply their gift card to the subtotal.

### Can an administrator manually generate gift cards?
**No.** Gift card vouchers are generated and dispatched strictly upon invoice creation of customer orders containing Gift Card products. There is no manual voucher generation form in the admin panel.

### Is the extension compatible with Multi-Currency stores?
**Yes.** The extension supports Magento's multi-currency architecture. Card values, custom amounts, discounts, and remaining balances convert dynamically according to configured currency exchange rates.

### Is the extension compatible with Hyvä Theme?
**Yes, via companion module.** The base `Webkul_GiftCard` extension provides standard Luma templates. Stores running Hyvä storefronts can install the **Webkul_GiftCardHyva** add-on for native Tailwind CSS and Alpine.js compatibility.
