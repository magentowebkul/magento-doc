# Manage Gift Cards & Accounts

The extension provides administrators with comprehensive grids to view, filter, and manage all generated gift card vouchers and linked customer balances.

Access these sections via the Admin menu:

**Gift Card > Manage Gift Cards**  
**Gift Card > Gift Card Accounts**

![Gift Card Menu](/images/final-gift-card-image.webp)

---

## 1. Manage Gift Cards Grid

The **Manage Gift Cards** interface (`wkgiftcard/giftcard/index`) displays all gift card vouchers produced by completed and invoiced customer purchases.

![Gift Card Details in Admin Panel](/images/final-gift-card-image.webp)

### Grid Columns

| Column | Description |
| :--- | :--- |
| **Entity ID** | Unique sequence identifier in the database. |
| **Gift Card Code** | Alphanumeric voucher code generated by the system (e.g., `1EIE5Z0TN8BZ5`). |
| **Price** | Face monetary value of the gift card certificate. |
| **Email** | Recipient email address designated to receive the voucher. |
| **From** | Sender name or email address of the purchasing customer. |
| **Expires At** | Expiration timestamp based on configured validity duration. |

---

## 2. Gift Card Accounts Grid

The **Gift Card Accounts** interface (`wkgiftcard/giftcardaccount/index`) tracks the current balance, usage, and active status of all gift card accounts.

![Gift Card Account Grid](/images/Screenshot-from-2023-06-14-12-32-48.png)

### Grid Columns

| Column | Description |
| :--- | :--- |
| **ID** | Account sequence identifier. |
| **From Email** | Email address of the purchaser. |
| **To Email** | Email address of the assigned card recipient. |
| **Code** | Gift voucher code. |
| **Price** | Initial allotted face value. |
| **Remaining Balance** | Current unspent funds remaining on the card. |
| **Allotted At** | Activation timestamp when the voucher was issued. |
| **Expiry** | Expiration date of the gift card account. |
| **Status** | Active or Inactive status (`is_active`). |
| **Expired** | Indicates whether the card has passed its expiration window (`is_expire`). |

---

## Administrative Actions

- **Status Management:** Administrators can enable or disable any gift card account directly from the grid using the status action (`ChangeStatus`), immediately halting or re-enabling its usability during checkout.
- **Search & Filtering:** Use standard Magento UI column filters (code, emails, date ranges) to audit customer balances and verify voucher statuses.
- **Automated Generation Policy:** Gift cards are generated strictly upon invoice generation of qualifying customer orders. There is no manual certificate creation form in the admin panel.
