# Magento 2 Service Fee - VuePress Documentation

Documentation for **Webkul Magento 2 Service Fee Extension** (`Webkul_ServiceFee`).

## Getting Started

### Installation

Install dependencies:

```bash
npm install
```

### Local Development

Run local development server with hot-reload at `http://localhost:8099`:

```bash
npm run start
# or
npm run docs
```

### Production Build

Build static site assets:

```bash
npm run build
```

The output files will be generated in `docs/.vuepress/dist`.
