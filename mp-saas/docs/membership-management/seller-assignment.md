# Seller Membership Assignment

Administrators can directly allocate or revoke SaaS membership plans for marketplace sellers in bulk, eliminating the requirement for vendors to complete manual storefront checkouts for promotional or managed accounts.

---

## Accessing the Manage Sellers Grid

Navigate to:
**Marketplace Management > Manage Seller**.

![Manage Sellers Grid](/images/image-17.png)
*Figure 8.5: Marketplace Manage Sellers grid with mass actions.*

---

## Bulk Assigning Membership Plans

To grant a SaaS membership plan to one or more sellers:

1. In the **Manage Seller** grid, select the target sellers using the row checkboxes.
2. In the top-left **Actions** drop-down menu, select **Assign a Membership Plan**.

![Assign Membership Plan Action](/images/image-18.png)
*Figure 8.6: Bulk assigning a membership plan to selected sellers.*

3. A secondary plan selector opens. Choose the desired membership plan (e.g., *Gold Monthly Plan*, *Annual Enterprise*).
4. Click **Submit** / **OK** to confirm.
5. The selected sellers receive tenant privileges, subdomain access, and 0% commission status immediately.

---

## Bulk Unassigning Membership Plans

If an administrator needs to revoke SaaS privileges or revert a seller to the standard commission model:

1. Select the sellers in the **Manage Seller** grid.
2. Under the **Actions** drop-down, select **Unassign a Membership Plan**.
3. Confirm the action when prompted.
4. The seller's active SaaS tier is terminated, and standard marketplace commission rules immediately re-apply to future orders.
