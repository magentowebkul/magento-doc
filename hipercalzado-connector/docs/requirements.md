# Requirements & Prerequisites

Before installing the **Hipercalzado Connector for Magento 2** extension, review the system compatibility and prerequisites outlined below.

## System Requirements

| Requirement | Supported Versions | Notes |
| :--- | :--- | :--- |
| **Magento** | `2.4.4` to `2.4.9+` | Open Source, Adobe Commerce, and B2B Editions |
| **PHP** | `8.1`, `8.2`, `8.3`, `8.4`, `8.5` | Standard PHP extensions |
| **Hipercalzado Account** | Active Merchant / Seller Account | User Token required for API authentication |
| **Storefront Themes** | Luma, Blank | Compatible across standard and modern storefronts |
| **Web Server** | Apache 2.4+ or Nginx 1.18+ | SSL Certificate (HTTPS) recommended for API operations |
| **Installation Directory** | `app/code/Webkul/Hipercalzado/` | Standard Magento 2 module location |

---

## Required Credentials & Verification

::: warning API Token Requirement
You MUST have an active Hipercalzado seller account and generate an API **User Token** prior to configuring the extension in Magento Admin.
:::
