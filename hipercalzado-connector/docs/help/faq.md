# FAQ & Support

Frequently asked questions and support resources for the **Hipercalzado Connector for Magento 2**.

---

## Frequently Asked Questions

::: details Are order status updates sent back to Hipercalzado automatically?
Yes. When an order status changes in Magento (e.g. `Shipped` or `Cancelled`), the Connector notifies the Hipercalzado API and updates the status on the marketplace.
:::

::: details Can I test order imports before going live on production?
Yes. Set **Enable Production Mode** to **No** under **Stores → Configuration → Webkul → Hipercalzado Connect** to test using sandbox API credentials.
:::

::: details Does the extension support custom shipping carriers?
Yes. You can select your default carrier under configuration or map custom carriers to match your Hipercalzado shipping configurations.
:::
