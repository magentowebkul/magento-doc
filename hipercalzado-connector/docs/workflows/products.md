# Hipercalzado Products Grid

Navigate to **Hipercalzado Connector → Hipercalzado Products** from the admin sidebar to view synchronized marketplace products.

![Hipercalzado Products grid in Magento 2 admin](/images/image-6.jpg)

---

## Grid Column Reference

| Column Name | Description |
| :--- | :--- |
| **Hipercalzado Product ID** | Unique item identifier assigned by the Hipercalzado marketplace. |
| **Thumbnail & Name** | Visual image preview and product title of the marketplace item. |
| **SKU & Type** | Product SKU code and type (Simple/Configurable). |
| **Store Product ID** | Corresponding Magento 2 internal Product ID. |
| **Action** | Click **View** to inspect the linked product record in Magento catalog. |
