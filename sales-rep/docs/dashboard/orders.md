# Orders Management

Navigate to **Sales Rep > Orders** to review and manage orders attributed to sales representatives.

![Orders](/images/orders.webp)

## Order Features

- **Filtered Order View**: Sales representatives only view orders linked to themselves or their assigned customers, keeping customer data secure and segregated.
- **Order Reassignment**: Representatives and managers can reassign existing orders to other colleague representatives.
- **Order Details Inspection**: Inspect purchased items, order status, billing/shipping addresses, and transaction totals.
- **Magento Order Workflow**: Create invoices, shipments, or credit memos according to granted Magento admin user role permissions.
