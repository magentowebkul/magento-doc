# Configuration Overview

Navigate to **Stores > Configuration > Webkul > Sales Rep** to configure the extension.

![Configuration Overview](/images/configg.webp)

## Configuration Sections

The configuration is divided into the following panels:

1. **[Dedicated Salesrep](/configuration/dedicated-salesrep.html)**: Enable the module and choose whether customers are assigned representatives manually or automatically (based on Product Rep, Category Rep, or First Contacted Rep).
2. **[Sales Rep Settings](/configuration/general-settings.html)**: Manage cart discount coupon behavior when negotiated quote items are in the cart.
3. **[Default Salesrep](/configuration/dedicated-salesrep.html#default-salesrep)**: Select default fallback representatives for Categories and Products.
4. **[Managers and Team](/configuration/managers-team.html)**: Define maximum manager limits and team size limits.
5. **[Mail & Email Notifications](/configuration/email-notifications.html)**: Set up default email sender credentials and customize 9 transactional email templates for orders, quotes, status changes, and customer messages.
