# Managers and Team Settings

Configure management hierarchies under **Stores > Configuration > Webkul > Sales Rep > Managers and Team**.

![Managers and Team](/images/four.webp)

## Team Configuration Settings

- **Max. Number of Managers of Sales Rep**: The maximum number of managers that can be assigned to a single sales representative user in the admin panel.
- **Max. Team Size**: The maximum number of subordinate sales representatives that can belong to a manager's team.

::: tip Managing Assignments
These thresholds control the capacity limits available when associating managers and team members under **Sales Rep > Sales Reps** on each representative's edit page.
:::
