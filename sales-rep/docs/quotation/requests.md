# Quote Requests

Customers can submit requests for custom quantity pricing directly from the storefront or their account portal, which are routed to the assigned sales representative.

## Frontend Quote Submission

### 1. Catalog Product Quote Request
Customers can request quotes directly from catalog product pages:

![Request Quote Button](/images/request-quote.png)

Clicking the button opens a modal window allowing them to specify quantities and target prices:

![Send Request Quote Modal](/images/send-request-quote-.png)

### 2. Multi-Product Quote Creation from Customer Account
Logged-in customers can also navigate to **My Account > Create Quote** (`salesrep/quote/create`) to build a comprehensive quote request:
- Search catalog products via live autocomplete by name or SKU.
- Configure custom or configurable product options.
- Set requested quantities and expected unit prices with automatic subtotal calculations.
- Add an overall project description before submitting.
