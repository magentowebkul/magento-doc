# Frequently Asked Questions

---

### Q1: Is the Multi Wishlist module compatible with Magento 2.4.9 and PHP 8.5?
**Yes.** The module supports Magento 2.4.x (up to 2.4.9) and PHP versions upto 8.5.

---

### Q2: How many wishlists can a customer create?
Customers can create an unlimited number of custom named wishlists.

---

### Q3: Can guest users save items into multiple wishlists?
**Yes.** Guests can select products and store them in wishlist cookie sessions. Once they log in or create an account, their items are automatically synced to their permanent customer account.

---

### Q4: Does this extension support headless / PWA storefronts?
**Yes.** The module includes built-in GraphQL queries (`getWishlistByCustomerId`, `getWishlistItemsByNameId`) and mutations (`addWishList`, `addItemsToWishlist`, `renameWishlist`, `deleteWishlist`, `addToCartAll`).

---

### Q5: Is the module compatible with Hyvä Themes?
**Yes.** Webkul provides an official compatibility package (`Webkul_MultiWishlistHyva`) that seamlessly replaces legacy Luma JavaScript with Alpine.js components and Tailwind CSS styling.

---

### Q6: Can customers share their wishlists with others?
**Yes.** Customers can share wishlists via email or direct sharing links with unique generated sharing codes.
