# Introduction

**Magento 2 Multi Wishlist** extension enables registered customers and guest shoppers to create, organize, share, and manage multiple named wishlists instead of relying on a single default wishlist.

By providing customers with personalized wishlist organization (e.g., *Birthday Ideas*, *Holiday Shopping*, *Favorites*), stores improve customer engagement, encourage repeat visits, and boost overall conversion rates. The module includes full headless GraphQL support and an official Hyvä compatibility package (`Webkul_MultiWishlistHyva`).

---

## Key Features

- **Multiple Named Wishlists:** Create unlimited custom wishlists, set default wishlists, rename, or delete existing ones.
- **Flexible Item Operations:** Move or copy items seamlessly between custom wishlists or directly into the shopping cart.
- **Wishlist Sharing:** Share custom wishlists with friends and family via email using unique sharing links.
- **Guest Wishlist & Cookie Sync:** Allows non-logged-in guest users to build wishlists, which automatically sync to their customer account upon login.
- **Admin Panel Management:** Store administrators can view, filter, and inspect customer wishlists and items directly from the Magento Admin backend.
- **Headless GraphQL APIs:** Fully supported GraphQL queries and mutations to fetch, create, update, rename, and clear wishlists for PWA / headless frontends.
- **Hyvä Theme Compatibility:** Dedicated compatibility module (`Webkul_MultiWishlistHyva`) featuring Alpine.js interactivity and Tailwind CSS styling.
