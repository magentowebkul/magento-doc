# Requirements

Before installing the **Magento 2 Multi Wishlist** extension, please ensure your environment meets the system and store requirements listed below.

---

## Store Environment Requirements

* **Magento Setup:** A working installation of Magento 2 / Adobe Commerce (supports versions 2.0.x through 2.4.x).
* **PHP Compatibility:** A PHP version that is compatible with your active Magento 2 setup.

---

## Hyvä Theme Requirements (Optional)

If your storefront is built using **Hyvä Themes**, you will also need:

* **Hyvä Theme Framework:** Active Hyvä default or custom child theme.
* **Hyvä Compat Module Fallback:** `Hyva_CompatModuleFallback` module enabled.

---

::: tip Backup Recommendation
Always create a full file and database backup before deploying any extension in a production environment. We recommend deploying and testing in a staging environment first.
:::
