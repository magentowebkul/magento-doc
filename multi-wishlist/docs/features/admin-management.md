# Admin Management

Store administrators can inspect, monitor, and review all customer wishlists and items directly from the Magento Admin Panel.

---

## Accessing Customer Wishlists in Admin

Store administrators can access and view customer wishlists through two navigation paths:

### Method A — Standalone Wishlist Grid
1. Log in to Magento Admin.
2. Navigate to **Wishlist > View Wishlist** (or **Webkul > Wishlist > View Wishlist**).
3. The main admin listing grid will display all wishlists created across all store customers.

![Admin Wishlist Grid](/images/admin_wishlist_grid.png)

### Method B — Customer Account Edit View
1. Log in to Magento Admin.
2. Go to **Customers > All Customers**.
3. Edit any customer record.
4. Select the **Wishlist / Multi Wish List** tab on the customer edit navigation menu.

![Admin View of Customer Wishlist](/images/admin_wishlist.png)
