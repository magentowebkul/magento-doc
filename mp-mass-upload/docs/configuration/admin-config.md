# Admin Panel Configuration

Before marketplace sellers can start mass uploading products, the store administrator must explicitly configure which product types sellers are allowed to upload from their frontend dashboard.

---

## Configuring Permitted Product Types

1. Log in to the **Magento Admin Panel**.
2. Navigate to **Stores > Configuration > Marketplace > Seller Product's Settings**.
3. Locate the **Product Type For Seller** field.
4. Select the product types sellers are allowed to add and mass upload (hold `Ctrl` or `Cmd` to select multiple options):
   * **Simple**
   * **Configurable**
   * **Virtual**
   * **Downloadable**
5. Click **Save Config**.

![Admin Configuration - Product Type For Seller](/images/image-5.png)

::: warning Important Restriction
Marketplace sellers can **only** mass upload product types that have been enabled by the administrator in this setting. If a product type is unselected, the seller will not be able to upload files for that product type.
:::
