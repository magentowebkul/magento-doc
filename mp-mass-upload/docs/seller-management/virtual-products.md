# Uploading Virtual Products

Virtual products represent non-tangible items like services, memberships, warranties, or digital subscriptions that do not require physical shipping or weight calculations.

---

## Virtual Product Upload Workflow

1. Go to **Mass Upload Product** in the seller panel.
2. Select the **Attribute Set**.
3. Attach the CSV/XLS/XML file and images ZIP.
4. Click **Upload Profile**.

![Virtual Product Profile Setup](/images/image-23.png)

5. Select the profile and click **Run Profile**.

![Profile Run Completion Message](/images/image-24.png)

---

## Virtual Product CSV File Format

In the import CSV file, enter all standard product details (SKU, name, price, description, status, tax class), but **omit the weight value** or leave the `weight` column blank/unassigned.

![Virtual Product CSV File Layout](/images/image-25.png)

Upon successful profile execution, virtual products will be listed under **My Product List**:

![Uploaded Virtual Products Grid](/images/image-26.png)
