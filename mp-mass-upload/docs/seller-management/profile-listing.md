# Profile Listing & Management

Sellers can monitor and clean up created upload profiles using the **Mass Upload Profile Listing** section.

---

## Managing Import Profiles

If an uploaded profile was not executed, contained invalid data, or is no longer needed:

1. Navigate to **Marketplace > Mass Upload Profile Listing** in the seller panel.
2. Review the list of all created upload profiles along with file type and status details.

![Seller Mass Upload Profile Listing Grid](/images/image-43.png)

3. Select unwanted profiles and delete them to keep the upload queue organized and clear unused file uploads from the server.
