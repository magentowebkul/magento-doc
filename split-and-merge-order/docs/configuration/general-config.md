# Module Configuration

After installing the **Magento 2 Order Split & Merge** extension, administrators can access and configure order processing rules, validation constraints, and automated merge routines from the Magento Admin Panel.

---

## Accessing Configuration

Store administrators can navigate to the configuration panel through two administrative paths:

### 1. Dedicated Admin Sidebar Menu
Click on the **Split And Merge Order** icon in the main Magento Admin sidebar. A flyout navigation menu opens containing:
- **Configuration Settings:** Direct shortcut to store configuration rules.
- **Support Links:** Quick access to the online User Guide, Store Extension page, Helpdesk Ticket / Customisations portal, Webkul Services, and Extension Reviews.

![Split And Merge Order Admin Menu](/images/admin-menu-split-merge.png)

---

### 2. Standard Store Configuration Path
1. In the Magento Admin Panel, navigate to **Stores > Settings > Configuration**.
2. In the left navigation menu, expand the **Webkul** section.
3. Click on **Split And Merge Order**.

![Split And Merge Order Configuration Panel](/images/configuration-sections-249.png)

---

## Configuration Sections Overview

Under the **Magento 2 Order Split & Merge** configuration section, the administrator will find four dedicated configuration panels:

| Configuration Section | Description |
| :--- | :--- |
| **General Configuration** | General module activation and core operational preferences. |
| **Merge Order Validations** | Defines thresholds for manual and programmatic merging, including minimum/maximum order count, order grand total bounds, collective weight limits, and condition checklists. |
| **Split Order Validations** | Establishes constraints under which an order qualifies for item-level or quantity splitting, including minimum item quantities and order pricing thresholds. |
| **Auto Merge Orders** | Configures automatic background order merging, customer identity rules, execution frequency, and automated shipping charge calculations. |
