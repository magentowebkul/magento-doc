# Frequently Asked Questions

Answers to common questions regarding the installation, configuration, and operation of the **Webkul Magento 2 Smart Device Based Promotions** extension.

---

## How does the module detect whether a customer is using a mobile or desktop device?
The module inspects the incoming HTTP `User-Agent` request header on the server side using Magento's built-in HTTP context detection. It classifies the visiting client as either **Mobile** (smartphones and mobile web clients) or **Desktop** (desktop computers and laptops) dynamically, without requiring client-side tracking cookies or third-party analytics scripts.

---

## Can I create automatic discounts that apply only to mobile users without requiring a coupon code?
Yes. Under **Marketing > Promotions > Cart Price Rules**, create a new rule with the **Coupon** option set to **No Coupon**. In the **Conditions** tab, select **Device Type is Mobile**. When a mobile shopper adds qualifying products to their cart, Magento automatically applies the discount to the order summary during checkout.

---

## Can I restrict a promotional coupon code so it cannot be redeemed on desktop browsers?
Yes. Under **Marketing > Promotions > Cart Price Rules**, set the **Coupon** field to **Specific Coupon** and enter your desired promo code. Under the **Conditions** tab, add `Device Type is Mobile`. If a customer attempts to enter this code on a desktop browser, Magento will reject the code and inform the customer that the coupon is not valid for their current device.

---

## How does the Geolocation targeting feature work with smart promotions?
When **Enable Location Specific Promotions** is set to **Yes** under **Stores > Configuration > Webkul > Smart Device Based Promotion Settings**, each promotional banner can be assigned to either **All Locations** or **Specific Countries**. The extension resolves the visitor's IP address to their country of origin and delivers the banner only to shoppers located in the configured countries.

---

## What metrics are tracked in the Promotions Dashboard?
The Promotions Dashboard (**Smart Device Based Promotions > Promotions Dashboard**) records sales and order performance categorized by device type:
- **Sales via Mobile**: Total revenue and order counts placed through mobile browsers.
- **Sales via Desktop**: Total revenue and order counts generated by desktop visitors.
- **Sales via Unknown**: Orders where device information was not identifiable.
Merchants can filter results by specific calendar months and device types to evaluate campaign conversion rates.

---

## Is this extension compatible with the Hyvä Theme?
Yes. The extension is fully compatible with [Hyvä Theme](https://webkul.com/hyva-theme-development/) via the official companion module package `Webkul_SmartDeviceBasePromotionsHyva` (`webkul/smart-device-base-promotions-hyva`), ensuring ultra-fast Alpine.js and Tailwind CSS storefront performance.

---

## Can I combine device type conditions with standard Magento cart conditions?
Yes. In Cart Price Rules, you can combine the **Device Type** condition with any native Magento condition, such as:
- Total cart subtotal equals or exceeds an amount
- Specific category IDs or product SKUs in cart
- Total item quantity
- Customer groups (e.g., General or Wholesale)

For example, you can create a rule: **Apply 20% discount if Device Type is Mobile AND Cart Subtotal is greater than $100**.

---

## What happens if a customer starts their cart on mobile and completes checkout on desktop?
If a customer adds products on a mobile device and transfers their cart to a desktop session (via a logged-in customer account), Magento re-evaluates the cart price rules dynamically during the active request. Any mobile-exclusive automatic discounts will be recalculated according to the active device completing the order.

---

## Does the extension impact storefront page load speeds?
No. Device classification is evaluated using efficient server-side header parsing during request bootstrap. No external API calls or blocking scripts are introduced, ensuring optimal Core Web Vitals and rapid page load speeds.
