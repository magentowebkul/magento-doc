# Hyvä Theme Compatibility

The **Magento 2 Store Optimization** extension is built to work seamlessly with **Hyvä Theme** as well as standard Magento Luma and Blank themes.

---

## Technical Highlights

* **Alpine.js & Tailwind CSS Friendly**: Does not interfere with Hyvä's lightweight JavaScript state engine or utility CSS compilation.
* **Intersection Observer Synchronization**: Integrates cleanly with Hyvä's native lazy loading and image rendering patterns.
* **No Third-Party Library Bloat**: Maintains Hyvä's core philosophy of speed and minimal dependencies.

---

## Hyvä Storefront Feature Showcase

All store optimization features function natively within the Hyvä Theme storefront layout:

**1. Image Optimization on Hyvä**
Automatically converts product, category, and CMS images to WebP or optimized JPEG format, drastically reducing payload size while keeping Hyvä's visual presentation crisp.

**.webp format**
![Hyva Image Optimization WebP](/images/hyva/image-optimization/01.png)

**.jpeg format**
![Hyva Image Optimization JPEG](/images/hyva/image-optimization/02.png)

---

**2. Defer Load JS on Hyvä**
Defers non-critical JavaScript scripts so Hyvä's lightweight HTML and Tailwind styles render instantly above-the-fold before background scripts execute.

![Hyva Defer Load JS](/images/feature/defe-loader/02.png)

---

**3. Infinite Scroller on Hyvä**
Eliminates traditional pagination on Hyvä category and search result pages, automatically loading upcoming product items as the shopper scrolls down.

![Hyva Infinite Catalog Scroll](/images/hyva/loader/01.png)

---

**4. Image Lazy Loader on Hyvä**
Delays loading off-screen product card images until they enter the browser viewport, preserving Hyvä's ultra-fast Initial Page Load (LCP).

![Hyva Image Lazy Loader](/images/hyva/image-lazy-loader/01.png)

---

**5. Cache Warmer on Hyvä**
Pre-generates Full Page Cache (FPC) for Hyvä category and product pages in the background, ensuring every shopper experiences sub-second page delivery.

![Hyva Cache Warmer](/images/feature/cache-warmer/01.png)

---

**6. Quicklink Options on Hyvä**
Monitors links in the Hyvä viewport during browser idle time and prefetches target pages in advance for near-instantaneous page transitions.

![Hyva Quicklink Fetch Priority](/images/feature/quick-link/08.png)
