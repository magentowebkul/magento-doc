# Mini-Cart QR Code Widget

When a customer adds products to their cart, a compact QR code widget with a live countdown timer appears inside the top header **Mini-Cart dropdown** across all storefront pages:

![Mini-Cart QR Code](/images/image-16.png)

## Highlights

* **Global Accessibility:** Accessible from any page (Category, Product Details, CMS pages) via the top header cart dropdown.
* **Live Expiration Timer:** Dynamic countdown badge displays exact remaining session TTL (`Expires in: mm:ss`).
* **Click to Enlarge Modal:** Tapping the thumbnail triggers the enlarged 2-column modal.
* **Cross-Device Transfer:** Quick mobile scanning directly from desktop header.
