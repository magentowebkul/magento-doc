# Enlarged 2-Column QR Code Modal

Clicking on the QR code or the *"Click to enlarge"* link opens a spacious, modern 2-column modal:

![Enlarged QR Code Modal](/images/image-19.png)

## Layout Features

* **Left Column:** Enlarged high-resolution QR code, live session countdown badge (`Expires in: mm:ss`), and **Share** button.
* **Right Column:** Visual **How-to-Scan** mobile infographic banner accompanied by clear, numbered step-by-step instructions.
