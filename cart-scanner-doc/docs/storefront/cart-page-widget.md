# Shopping Cart Page Widget

On the shopping cart page (`/checkout/cart`), the customer sees the full Cart Scanner widget featuring the QR code thumbnail, live expiration countdown badge, custom instructions, and the **Share** button:

![Shopping Cart Page Widget](/images/image-18.png)

## Key Elements

* **QR Code Preview:** Instant visual representation of the active cart token.
* **Expiration Countdown Pill:** Live badge showing remaining token validity.
* **Click to Enlarge Trigger:** Launches the 2-column modal popup.
* **Multi-Channel Sharing:** Quick sharing across social messaging platforms.
