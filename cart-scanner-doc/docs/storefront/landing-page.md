# Dedicated Cart Scanner Landing Page

Shoppers can navigate directly to the dedicated scan landing page by clicking the **"Scan QR Code"** link in the header panel or visiting `/cartscanner/index/scan`.

The landing page offers a clean, distraction-free interface for seamless cross-device shopping:

![Dedicated Cart Scanner Landing Page](/images/image-24.png)

## Page Layout & Features

* **Step-by-Step Instructions:** Clearly guides customers through opening their mobile camera or browser, locating the scanner icon `[▪]`, and instantly syncing cart contents.
* **Dynamic Live QR Code Card:** Displays the high-resolution QR code for the active cart, equipped with a live green expiration countdown badge (`Expires in: mm:ss`) and a unified **Share** button for copying links or sending via messaging apps.
* **Smart Empty State:** If the shopper's cart is empty, the card gracefully adapts to display a friendly notification with a quick link to start shopping.
