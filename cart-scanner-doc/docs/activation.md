# Activate & Connect

Once installation commands complete successfully, activate and configure the Shopping Cart Scanner module in the admin backend.

## Step 1: Admin Access

1. Log in to your Magento 2 Admin Panel.
2. Navigate to **Stores > Configuration > Webkul > Cart Scanner** (or **Cart Scanner > Configuration Settings**).

## Step 2: Enable Module

Set **Module Enabled** to **Yes** under **General Settings** to activate QR code generation and storefront widgets.

::: tip Quick Verification
Visit your storefront, add a product to your cart, and open the header mini-cart dropdown or visit `/cartscanner/index/scan` to verify that the dynamic QR code widget renders correctly.
:::
