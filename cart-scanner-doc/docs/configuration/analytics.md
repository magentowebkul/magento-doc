# Analytics Settings

Configure real-time scan analytics and order conversion tracking under **Stores > Configuration > Webkul > Cart Scanner > Analytics & Conversion Tracking**.

![Analytics Settings](/images/image-9.png)

## Setting Fields

### Enable Scan Analytics & Conversion Tracking
* **Options:** `Yes` / `No`
* **Description:** Enables automatic logging of QR scan events, user agent device types (iOS, Android, Desktop), mobile checkout conversions, and revenue metrics displayed in the Admin Scan Analytics grid (**Cart Scanner > Scan Analytics & Reports**).
