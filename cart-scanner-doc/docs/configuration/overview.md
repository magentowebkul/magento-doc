# Configuration Overview

To access the configuration options for the Shopping Cart Scanner module:

1. Log into the Magento Admin Panel.
2. Go to **Stores > Configuration > Webkul > Cart Scanner** or **Cart Scanner > Configuration Settings**.

The configuration settings are structured into logical panels:

* **[General Settings](/configuration/general-settings.html):** Enable the module, select cart synchronization behavior, and define QR code expiration times.
* **[Display Customization](/configuration/display-customization.html):** Customize widget header titles, instructions text, and header mini-cart visibility.
* **[Cart Sharing Options](/configuration/cart-sharing.html):** Enable native sharing and customize social share messages.
* **[Analytics Settings](/configuration/analytics.html):** Turn on scan analytics and order conversion tracking.
