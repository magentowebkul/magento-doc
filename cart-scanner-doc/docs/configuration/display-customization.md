# Display & Widget Customization

Customize storefront UI labels, promo copy, and mini-cart integration settings under **Stores > Configuration > Webkul > Cart Scanner > Display & Widget Customization**.

![Display and Widget Customization](/images/image-7.png)

## Setting Fields

### Widget Title
* **Type:** Text Input
* **Default:** `Scan & Buy on Mobile`
* **Description:** Title text displayed above the QR code block on the shopping cart page widget and modal popup.

### Instructions Text
* **Type:** Text Area / Multi-line Input
* **Description:** Explanatory copy shown alongside the QR code guiding shoppers on how to scan with their mobile phone.

### Display in Mini-Cart
* **Options:** `Yes` / `No`
* **Description:** Controls whether the compact QR code widget with a live expiration countdown timer appears inside the top navigation header mini-cart dropdown.
