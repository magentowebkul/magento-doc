# Cart Sharing Options

Configure cart sharing controls and social pre-filled copy under **Stores > Configuration > Webkul > Cart Scanner > Cart Sharing Options**.

![Cart Sharing Options](/images/image-8.png)

## Setting Fields

### Enable Cart Share
* **Options:** `Yes` / `No`
* **Description:** Displays the unified **Share** button on the cart scanner widget, landing page, and enlarged modal. Enables native Web Share API on supported devices and clipboard copy fallback.

### Share Message Prefix
* **Type:** Text Input
* **Default:** `🛒 Your cart is ready! Tap here to complete your order:`
* **Description:** Pre-filled text prepended to the dynamic cart link when shared via messaging or social applications (WhatsApp, Telegram, iMessage, Email).
