# Multi-Lingual Configuration

For multilingual support across store views, navigate to **Stores > Configuration > General > General > Locale Options** and select your desired language:

![Locale Options](/images/image-2.png)

## Setting Up Store Locale

1. In the Magento Admin Panel, go to **Stores > Configuration > General > General**.
2. Open the **Locale Options** tab.
3. Uncheck **Use Website** if applicable, then select the target store view language from the **Locale** selector dropdown.
4. Save configuration and flush Magento cache.
