# Introduction

The **Shopping Cart Scanner module for Magento 2 (Adobe Commerce)** allows shoppers to instantly transfer and synchronize their shopping cart from desktop to mobile devices using a secure, dynamic QR code. Customers can scan the QR code using their smartphone camera or mobile browser to complete their purchase on mobile seamlessly.

Additionally, this module provides real-time token security with live countdown timers, multi-channel cart sharing, compact Mini-Cart widget integration, a dedicated landing page, and a comprehensive **Scan Analytics & Conversion Tracking** dashboard for store administrators.

::: tip Theme Compatibility
This module is fully compatible with standard Magento 2 (Luma theme), Progressive Web Applications (PWA), and **Hyvä Theme** via the `Webkul_CartScannerHyva` compatibility package.
:::

## Key Features

* **Offline & Online Cart Scanning:** Scan and sync shopping carts seamlessly across devices.
* **Dedicated Cart Scanner Landing Page:** Standalone `/cartscanner/index/scan` page featuring a modern 2-column hero layout, 3-step mobile scan walkthrough, dynamic live QR code card, live countdown timer pill, unified share button, and bottom visual infographic showcase banner.
* **Header Mini-Cart Integration:** Compact QR code widget with a live countdown timer directly in the header mini-cart dropdown.
* **Shopping Cart Page Widget:** Prominent QR code widget with instant "Click to Enlarge" popup modal and multi-channel sharing options.
* **2-Column Enlarged QR Modal:** High-resolution QR code popup featuring a visual **How-to-Scan** mobile mockup and step-by-step onboarding guide.
* **Live Countdown Timer & Real-Time Expiration:** Configurable token TTL (Time-To-Live) with dynamic countdown badges and one-click instant QR refresh.
* **Cart Sync Strategies:** Choose between *Merge with existing mobile cart* or *Replace mobile cart*.
* **Multi-Channel Cart Sharing:** Native Web Share API integration with clipboard copy fallback for WhatsApp, email, SMS, and social apps.
* **Admin Scan Analytics & Conversion Tracking:** Real-time KPI stat cards (Total Scans, Converted Orders, Conversion Rate, Generated Revenue) and detailed UI Grid reporting.
* **Mobile In-App Scanner:** Dedicated camera scanner icon `[▪]` in the mobile header with torch/flashlight toggle and audio-haptic scan confirmation.
* **Mobile-Responsive Adaptive Layouts:** Optimized for all screen sizes from wide desktop screens down to smartphones.
* **Guest & Registered Customer Support:** Fully functional for both guest shoppers and logged-in accounts.
