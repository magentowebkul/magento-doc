# Frontend Chat Window Options

Customizes widget appearance, placement, and guest accessibility on the storefront.

## Chat Window Fields

| Field | Description |
|---|---|
| **Enable Guest Mode** | Set to `Yes` to allow non-logged-in visitors to converse with the chatbot. If `No`, visitors must log in or register before chatting. |
| **Chat Window Position** | Choose launcher position on the storefront (`Bottom Right` or `Bottom Left`). |
| **Chat Window Background Type** | Select background styling: `Solid Color` or `Image`. |
| **Choose Background Color** | Set background color when *Solid Color* is selected. |
| **Chat Window Background Image** | Upload a custom background image when *Image* is selected. |
| **Chat Window Icon Background Color** | Custom color for the floating chat launcher button. |
| **Chat Window Icon Color** | Icon color inside the launcher button. |
| **Chatbot Text Background Color** | Background color of customer message bubbles. |
| **Customer Text Color** | Font color for customer messages. |
| **Customer Reply Text Background Color** | Background color of chatbot assistant message bubbles. |
| **ChatBot Reply Text Color** | Font color for chatbot assistant messages. |
