# AI Model Type: Pre Configured Model

Connect the chatbot to a dedicated, self-hosted inference server instead of a cloud provider.

![Pre Configured Model settings](/images/chatbot-ai-service-type-preconfigured.png)

## Pre Configured Model Fields

| Field | Description |
|---|---|
| **Use AI Node Server** | Set to `Yes` if running via the companion Node.js server. |
| **Server Endpoint** | Enter the URL of the inference endpoint (e.g., `http://ai-server.example.com:8000`). |
| **API KEY** | Enter the authentication API token for the server. |
