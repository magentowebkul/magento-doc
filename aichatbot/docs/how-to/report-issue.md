# Report Issue to Admin

If a customer encounters a problem or requires human assistance, they can submit an issue report directly from the chat header.

## Submit an Issue Report

1. Click the **Report to Admin** icon in the chat header.
2. Enter the **Report Subject** and **Describe Issue** in the modal form.
3. Click **Submit Report**.

![Report issue form](/images/chatbot-report-issue-to-admin-form.png)

The inquiry is immediately logged in the Magento Admin under **AI ChatBot > Chat Reports** for administrator review.
