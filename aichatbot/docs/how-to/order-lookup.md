# Order Lookup & Tracking

Logged-in customers can check order details and shipment tracking directly inside the chat interface without navigating to the My Account section.

## Step 1: Browse Recent Orders

Selecting **"Check your orders"** lists the customer's recent orders with thumbnail, order number, date, and current status:

![Orders list](/images/chatbot-orders-list.png)

## Step 2: Select an Order Query Option

Clicking on an order reveals interactive action options:

![Check order options](/images/chatbot-check-order-options.png)

Available options include:

- **Check order status**: Instant summary of current fulfillment state (Pending, Processing, Complete).
- **Order summary**: High-level overview of the order date, items count, and total.
- **Detailed items breakdown**: Comprehensive invoice list with itemized prices and quantities.
- **Shipping and tracking**: Direct shipment carrier info and tracking links.

> To view the full order breakdown, see **[View Order Details](/how-to/order-details)**.
