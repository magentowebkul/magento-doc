# Requirements & Prerequisites

Review the system requirements, supported platforms, and prerequisite credentials before installing **Magento 2 Parcel Perfect Shipping**.

---

## Supported Versions

| Requirement | Supported Specifications | Notes |
| :--- | :--- | :--- |
| **Supported Magento Versions** | `2.0.x`, `2.1.x`, `2.2.x`, `2.3.x`, `2.4.x`, `2.4.9` | Open Source & Adobe Commerce |
| **Supported PHP Versions** | `7.4`, `8.1`, `8.2`, `8.3`, `8.4`, `8.5` | Matches PHP requirements of your specific Magento 2 version |
| **Supported Database** | MySQL `5.7+` / `8.0+` or MariaDB `10.4+` | Standard Magento database stack |
| **Web Server** | Apache `2.4+` / Nginx `1.18+` | With SSL enabled for secure API communications |

---

## Supported Shipping Coverage

Parcel Perfect Shipping supports shipping calculation and parcel dispatch for:
- **Southern Africa** (South Africa, Namibia, Botswana, Zimbabwe, Mozambique, Swaziland, Lesotho, etc.)
- **United Kingdom & Europe**
- **United States of America**
- **Australia**
- **Singapore**
- **Hong Kong**
- **Mainland China**

::: tip Coverage Scope
Available destination countries, postal codes, and delivery lanes depend on the service zones contracted under your specific Parcel Perfect courier merchant account (`PPCUST No.`).
:::

---

## Merchant Account Requirements

To connect Magento with Parcel Perfect web services, you must obtain an active account with Parcel Perfect:
1. **Parcel Perfect Account Username & Password**
2. **Parcel Perfect Customer Number**
3. **Web-Service Server URL** (Sandbox URL for testing and Live URL for production)

::: tip Getting Credentials
Refer to the [Parcel Perfect Credentials](/configuration/credentials.html) guide for instructions on requesting an e-commerce test account.
:::

::: info Next Step
Once your credentials and server environment are ready, proceed to the [Installation Guide](/installation.html).
:::
