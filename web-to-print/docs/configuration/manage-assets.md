# Print Assets Management

Before designing product templates, populate your design assets in the **Web To Print** admin menu. These assets provide typography, preset color palettes, and stock graphics that customers can incorporate into their personalized artwork.

---

## 1. Image Categories

Image categories group clip art, decorative borders, icons, and illustrations into logical catalogs.

### Adding an Image Category
1. Navigate to **Web To Print** > **Image Category**.
2. Click **Add Images Category** in the top action bar.
3. Complete the category form:
   - **Category Name**: Display name for the category (e.g., *Animals*, *Vintage Badges*, *Wedding Emblems*).
   - **Category Description**: Brief description of the graphics contained.
   - **Thumbnail**: Upload a representative icon or preview graphic for the category.
4. Click **Save Category**.

![Adding Image Category](/images/web-to-print-category-image.webp)

::: tip Bulk Actions
From the **Image Category** grid, you can select multiple categories and perform mass deletion using the **Actions** dropdown menu.
:::

---

## 2. Stock Images & Clip Arts

Upload graphics into your categories so buyers can drag and drop them onto their canvas.

### Uploading an Image
1. Navigate to **Web To Print** > **Images**.
2. Click **Add Image**.
3. Fill in the required details:
   - **Category**: Select the parent category created in the previous step.
   - **Upload Image**: Choose a high-resolution raster image (`.png`, `.jpg`) or vector file (`.svg`) from your local device. Transparent PNGs are recommended so graphics blend cleanly over background product colors.
   - **Description**: Add descriptive alt text for accessibility and identification.
4. Click **Save Image**.

![Uploading Image](/images/web-to-print-add-image.webp)

---

## 3. Custom Fonts (WTP Fonts)

Give customers typographic freedom by uploading custom typography packages.

### Adding a Font
1. Navigate to **Web To Print** > **WTP Fonts**.
2. Click **Add Fonts**.
3. Provide the font details:
   - **Font Name**: Human-readable name displayed in the canvas font selector (e.g., *Bebas Neue*, *Pacifico*, *Montserrat Bold*).
   - **Font Library**: Upload the font file (`.ttf` or `.otf` format).
4. Click **Save Font**.

![Uploading Font](/images/web-to-print-font.webp)

Once uploaded, the font is automatically registered and rendered dynamically in the canvas typography dropdown menu.

---

## 4. Predefined Colors (WTP Colors)

While customers can select custom colors using an interactive color picker or HEX input, you can create a curated brand palette for rapid selection.

### Adding a Predefined Color
1. Navigate to **Web To Print** > **WTP Color**.
2. Click **Add New Color**.
3. Configure the color swatch:
   - **Color Name**: Name of the hue (e.g., *Crimson Red*, *Royal Navy*, *Gold Leaf*).
   - **Color Code**: Hexadecimal color code (e.g., `#E63946`) or select a hue using the color picker widget.
4. Click **Save Color**.

![Adding Color Swatch](/images/web-to-print-color.webp)

---

## Asset Grid Management & Mass Actions

All asset grids (Categories, Images, Fonts, Colors) feature:
- Column sorting and keyword search filters.
- Individual edit and delete actions.
- **Mass Delete**: Check multiple rows and select **Delete** from the mass actions control to quickly prune legacy assets.
