# FAQ & Support

Frequently Asked Questions and technical support resources for **Magento 2 Multi Vendor Custom Option**.

---

## Frequently Asked Questions

### Q1: Can marketplace vendors set different input types for different options?
Yes. Vendors can combine multiple input types (e.g., Text Field for engraving, Drop-Down for material, File Upload for logo, Date Picker for delivery date) on the same product.

### Q2: Does the module support percentage-based price adjustments?
Yes. Sellers can choose between **Fixed** dollar amounts ($) or **Percentage** (%) price additions calculated relative to the product base price.

### Q3: Are custom options compatible with Hyvä Theme?
Yes. The extension is fully compatible with native Magento 2 Luma themes and **Hyvä Themes**, ensuring high performance on modern storefronts.

### Q4: Can administrators restrict sellers from creating custom options?
Yes. Admin can globally toggle **Enable Custom Option for Sellers** to **No** under **Stores → Configuration → Webkul → Custom Option**.
