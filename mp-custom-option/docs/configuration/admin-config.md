# Admin Configuration

Configure global seller custom option permission settings in the Magento 2 Admin Panel.

---

## Global Seller Permission Configuration

1. Log in to the Magento 2 Admin Panel.
2. Navigate to **Stores → Configuration → Webkul → Custom Option**.

![Admin Configuration Screen](/images/image-8.png)

3. Configure the following field:
   - **Enable Custom Option for Sellers:** Select **Yes** to allow marketplace vendors to create custom options in their vendor panel. Select **No** to hide the custom option section in vendor product management screens.
4. Click **Save Config**.
5. Flush Magento cache if prompted (**System → Cache Management → Flush Magento Cache**).
