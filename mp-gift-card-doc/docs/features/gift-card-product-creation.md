# Gift Card Product Creation

With **Webkul Magento 2 Marketplace Gift Card**, both the **Store Administrator** and **Marketplace Sellers** have full capability to create and list Gift Card products.

Gift Cards function similarly to standard virtual catalog products with customizable options for recipient details.

---

## Admin Workflow: Creating a Gift Card Product

1. Navigate to **Catalog > Products** in the Magento Admin panel.
2. Click the dropdown arrow next to **Add Product** and select **Marketplace Gift Card** (or Virtual Product with Gift Card attributes).

![Add Product Dropdown](/images/feature/01.png)

3. Fill in the required product attributes:
   - **Product Name**: E.g., *Holiday Gift Voucher*, *Birthday Gift Card*.
   - **SKU**: E.g., `gift-card-birthday`.
   - **Price**: Face value of the gift card (e.g., `$100.00`).
   - **Special Price**: Optional discounted price (e.g., `$90.00`).
   - **Quantity**: Set inventory quantity (or set to *In Stock*).
   - **Categories**: Select store catalog categories.

## Product Display on Storefront

Once saved, the Gift Card product displays on the store frontend with custom input fields:

- **Price Tag**: Shows face value or special promotional price.
- **Email To Input Box**: Accepts the recipient's email address.
- **Message Input Box**: Allows the buyer to type a message (e.g., *"Happy Birthday John! Enjoy your gift!"*).
- **Add to Cart Button**: Adds the configured virtual gift card to the customer's cart.

::: note NOTE

:::
