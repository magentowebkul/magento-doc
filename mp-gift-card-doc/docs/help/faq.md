# Frequently Asked Questions (FAQ)

### Q1: Can a single Gift Card code be used multiple times?
**Yes.** The extension supports partial redemptions. Customers can use a single gift card code across multiple purchases until the remaining balance is fully exhausted.

### Q2: Can Marketplace Vendors create Gift Card products?
**Yes.** Both store administrators and marketplace sellers can create gift card products from their respective management panels. Sellers can also configure special prices for their gift cards.

### Q3: How is the Gift Card code delivered to the recipient?
Once the buyer completes payment and the order status becomes **Invoiced / Complete**, an automated transactional email is generated and sent to the recipient's email address with the gift code, personal message, initial balance, and expiration date.

### Q4: Can customers purchase a Gift Card using an existing Gift Card code?
This behavior is configurable by the store administrator. In `Stores > Configuration > Webkul > Gift Card > Apply Gift Card Code On Gift Card Product`, set the option to **Yes** to allow purchasing gift cards with existing gift card codes, or **No** to restrict it.

### Q5: What happens when a Gift Card code expires?
Gift card expiration is calculated based on the **Gift Card Active Duration (No. of days)** setting. Once expired, the code status updates to **Expired** and it cannot be redeemed at checkout.

### Q6: Does the extension support Headless / PWA storefronts?
**Yes.** The extension includes complete GraphQL schema definitions, mutations, and queries for seamless PWA and headless application integration.
