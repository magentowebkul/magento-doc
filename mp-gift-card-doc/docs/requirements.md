# System Requirements

Before installing the **Webkul Magento 2 Marketplace Gift Card** extension, ensure your environment meets the software, PHP, and dependency prerequisites detailed below.

---

## Server & Magento Requirements

- **Magento Setup**: - A working installation of Magento 2 / Adobe Commerce (supports versions 2.0.x through 2.4.x).
- **PHP Version**: A PHP version that is compatible with your active Magento 2 setup.

---

## Webkul Multi Vendor Marketplace

To integrate this module, you must have an active installation of the **Magento 2 Multi Vendor Marketplace**. This module acts as an add-on and will not function independently.

You can purchase or learn more about the marketplace extension here: [**Magento 2 Multi Vendor Marketplace**](https://store.webkul.com/magento2-multi-vendor-marketplace.html)

::: note Important
Always back up your store (database and files) before installing any new extension. We recommend deploying and testing in a staging environment first.
:::
